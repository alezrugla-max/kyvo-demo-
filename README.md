# Kyvo

Live Solana memecoin feed + **Viral z X** snapshot.

- **Live:** DexScreener (profiles, boosts, search, token pairs). Fallback: GeckoTerminal trending.
- **Viral z X:** static `data/x_viral.json` (real posts; refresh via `tools/update_x_viral.md`). Topics fuzzy-matched to coins live.
- **Not financial advice.** No accounts, no server-side tracking, no custody.

Marker: `KYVO_MVP_LIVE_v4`
